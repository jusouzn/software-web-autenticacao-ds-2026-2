# Introdução

> **Autoria:** Kesley Soares da Silva · **Revisão:** Júlia de Souza Nascimento e Verônica Ribeiro Oliveira Palmeira · Apoio de IA: [[ANTHROPIC, 2026](../referencias.md#ref-anthropic2026)]

Este documento apresenta o projeto de um Software Web para Autenticação de Usuários, conforme o escopo definido pela disciplina: o software recebe credenciais, verifica se correspondem a um usuário válido e retorna a identidade desse usuário quando a autenticação é bem-sucedida, ou um erro de autenticação em caso contrário. Nenhuma outra funcionalidade (cadastro, recuperação de senha, sessão, autorização) faz parte do escopo.

O corpo do documento está organizado em duas seções. A [Seção 1](1.1-componentes.md#1-ambiente-operacional-da-aplicação-web) explica o ambiente operacional em que a aplicação é executada, descrevendo cada software de apoio (navegador, servidor DNS, servidor web, servidor de aplicação e sistema gerenciador de banco de dados), a forma como cada um é invocado e os resultados que produz durante o processamento de uma requisição. A [Seção 2](../02-projeto/2.1-requisitos.md#2-projeto-da-arquitetura-e-desenho-detalhado-de-componentes) apresenta o projeto da arquitetura e o desenho detalhado dos componentes da solução. Seguem-se as referências bibliográficas e os apêndices, que contêm os prompts submetidos à ferramenta de Inteligência Artificial (IA), o plano de trabalho e de riscos da equipe e os registros de comunicação.

Cada item de informação é identificado por um código (IT-x.y) e traz, no início, a indicação de autoria, revisão e referências utilizadas. A consolidação dessas atribuições está na Tabela 1. Todos os artefatos estão sob gerência de configuração no repositório GitHub da equipe (`jusouzn/software-web-autenticacao-ds-2026-2`), organizado segundo o processo de gestão de configuração descrito na norma [[ISO/IEC/IEEE, 2026](../referencias.md#ref-iso12207)].
